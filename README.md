# MyPlaces - An Adaptive Mobile Map Application

## About

This project is a master's thesis research application called "MyPlaces" that was developed at the University of Zurich (UZH) under the Geographic Information Visualisation and Analysis (GIVA) group to conduct research about the technical and logical feasibility of adaptive mobile map applications. It should serve as a prototype and should be used as a basis platform for further improvements, implementations and research.

## Author

Johannes Guler

## Usage

The application was developed in the Xcode IDE and connects to a Esri ArcGIS Online or ArcGIS Location platform account via API Key. There, the geographic data used for geovisualisation is hosted and then loaded into the app logic.

**Application Files**
Each file has a short functionality description and overview at the top
- `MyPlaces/` - All the code structure that is used by MyPlaces Application
- `MyPlaces/CoreData Model/` - Core Data of the application
- `MyPlaces/Managers/` - Data structure and business logic of the application
- `MyPlaces/Models/` - The logical components of the Application for operation and orchestration
- `MyPlaces/Resources/` - Hosts the two ML models and fclass conversion files for score calculations
- `MyPlaces/Views/` - All the objects responsible for the different visualisations in the application

**Recommender System**
- `RecommenderSystem/` - All the files used to train the two ML models
- `RecommenderSystem/Relevance Model/` - Files used to train the RM based on synthetic data generated by a rule based logical system
- `RecommenderSystem/Thematic Model/` - The files for TM training
- `RecommenderSystem/Specific Calculations/` - Additional helper files to calcualte Cluster & Co-Location attributes of the POIs as well as test the influence of distance on the relevance score
